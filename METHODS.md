# Screening methods and limitations

**Study area.** OSM way 115105262 (NTU `amenity=university`) is the working polygon. It is community mapping and needs official/field validation. The source query bbox is larger; buildings outside the working polygon are retained but flagged and are not counted as campus assets. OSM way geometry is repaired if invalid; lengths/areas and 100 m grid are computed in EPSG:3414, then published as EPSG:4326 GeoJSON. Nonwalkable explicit `foot=no/private` and `access=no/private` are excluded. Bridges, tunnels, indoor/layer information remain attributes; no two-dimensional crossing is turned into a network connection.

**Weather.** Each raw NEA daily response retains original timezone timestamp, station metadata, reading type and unit. Only S44 readings enter the current campus screening; no substitute station is renamed S44. Duplicate source+station+variable+timestamp rows are removed. Temperature, humidity and wind are one-minute samples; wind knots are multiplied by 0.514444 to m/s, while raw values remain. Rainfall is 5-minute interval total in mm with timestamp at the interval end. Aggregation attributes each interval to its start hour/day, sums nonoverlapping rainfall, and averages sampled temperature/humidity/wind. Missing rainfall stays NaN, partial sums are marked partial. The 80% completeness threshold is an engineering selection rule, not a meteorological quality standard. Suspect values are flagged by broad screening bounds, retained in raw observations and excluded from aggregation.

**Heat proxy.** For each valid observed minute, `H = Σ max(T_t − T0, 0) × (1/60 h)` with default T0=30°C. Missing minutes contribute neither heat nor valid duration; there is no forward fill. Report H (°C·h), valid hours, coverage and H/valid hour. This is a sample-specific exploratory threshold, not WBGT, UTCI, a health probability or a heat alert.

For grid cell `i`, OSM walking line lengths are divided into `covered=yes`, `covered=no` and missing/other. `L_eff = L_no + q_unknown × L_unknown`; `P_i = H × L_eff` (°C·h·m). Default q=0.5 is an assumption, and q=0/1 define a sensitivity range, not confidence bounds. The fixed covered tag omits trees, time-varying shadows and radiation. Covered ways can still be hot; their exclusion is only from this narrow unprotected-length proxy. There are no pedestrian counts or vulnerability weights.

**Scenarios.** +1/+2°C adds to the same observed temperature timestamps. Rain ×1.1/×1.2 scales the same observed hourly event, without filling missing intervals or changing event timing; a configurable threshold counts qualifying sample hours after each scaling. Those threshold crossings are not future event-frequency projections. Shelter 25/50% lowers `L_eff` only in listed grid IDs. All variants preserve sample mask, grid and color scale. Proxy reduction is formula-driven and does not establish a measured temperature, health or economic benefit. A zero baseline produces an undefined percentage change. No drainage/terrain inputs support flood depth, flood probability or inundated-building counts. The 30-day observational sample is not a climatological normal or climate trend.

**3D.** When available, OSM `height` is used. Otherwise OSM `building:levels × 3.2 m` is an explicit display assumption. Buildings with neither height source use a 10 m display height only for browsing. These geometries are not BIM and do not drive shadow, wind or flood calculations.
# OSM 最短路径扩展

新增网格路线经过次数：在缓存 OSM 节点拓扑上，以 EPSG:3414 米制路段长度运行 Dijkstra；对宿舍 × LT／图书馆／食堂的等权 OD 组合分别选一条最短路。同一路线在同一网格计一次，仅角点接触不计。候选点匹配距离、不可达 OD、分类计数和输入哈希均导出。定义、匹配假设和复核流程见 [ROUTING.md](ROUTING.md)。原有热暴露与遮棚情景指标未作修改。
